# Regent Way

Luxury residential platform for **flats and penthouses in Gurugram**. Black + gold. WhatsApp is the only lead line.

Listings: **`src/lib/listings.ts`** — 8 Gurugram homes. Each has image paths under `/public/listings`.

Stills in `/public/listings` and `/public/interiors` are **preview assets**. Swap for real photos from the owner dashboard. Keep the “Preview asset” ribbon until then.
